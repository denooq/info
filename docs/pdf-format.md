# PDF декларации

PDF создаёт `PdfDeclaration` через mPDF с локальным DejaVu Sans. Имена, адреса и описания экранируются как текст, удалённые шрифты и картинки не используются. Печать получает единственную подтверждённую структуру данных, а не исходные файлы и не повторный ответ AI.

Основной лист содержит общие графы и первый товар. На добавочном листе размещаются до трёх следующих товаров. Для пяти товаров нумерация форм — 1/3, 2/3, 3/3. Длинные графы имеют ссылку на продолжение, полный текст печатается после форм с номером графы и товара. Такие страницы не увеличивают число форм в графе 3 и число добавочных листов при расчёте сбора. Количество физических страниц PDF может быть больше.

Графа 44 печатает один и тот же код представления, который выбран в данных документа. Номер 10-18/332 не имеет фиксированного кода из примера. Регистрационный номер графы A остаётся пустым; статус выпуска и утверждение об электронной подписи не переносятся из образцов. Отдельный PDF ДТС не создаётся.

Автоматические проверки извлекают текст из полученного PDF и проверяют Unicode, суммы, номера, коды представления и сохранность конца длинного описания. Визуально проверяется основной лист, три товара на добавочном листе и продолжения. Шаблон является программной печатной формой MVP; его проверка не означает проверку импорта XML в Keden.
