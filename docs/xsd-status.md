# Статус официальных схем

По решению пользователя от 12.11.2026 официальные XSD перенесены на следующий этап. Задача 1.4 текущего изменения теперь закрепляет профили XML-образцов, а не получение схем. В reference XSD нет; официальный реестр `https://rseds.eaeunion.org/ru/` при проверках отвечал тайм-аутом.

Требуются R.055 GoodsDeclaration v1.2.0 (CA v1.10.3, common v0.4.16 из примера) и R.038 CustomsValueDeclaration v1.5.0 (CA v1.8.1, common v0.4.14 из примера). Версии сохраняются по согласованным образцам; новые редакции не подставляются молча. Подтверждённого комплекта схем оболочки Keden нет.

Текущий экспорт проверяет локальную структуру образцов и согласованность данных, без утверждения «XSD пройдена». Отсутствие XSD не блокирует поддержанные случаи. Непредставленные в образце ветки блокируются с объяснением по отдельному решению пользователя. Собственная ослабленная XSD не создаётся. Детали — [профили XML](xml-profiles.md).
