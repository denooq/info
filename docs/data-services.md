# Обработка документов

Backend вызывает Mistral OCR 4.1 для PDF/JPEG/PNG и сохраняет страницы, таблицы и блоки. XLSX читается потоково по ячейкам без загрузки рисунков. Затем Mistral Small 4 сопоставляет текст с разрешёнными полями реестра через строгий JSON Schema. Расчёты и юридически значимые ставки AI не определяет.

Ключ находится только в приватном PHP config или MISTRAL_API_KEY. Запросы требуют TLS-проверки, ограничены временем/размером ответа и не выполняются из браузера. Очередь файловая, с блокировками и ограниченным числом повторов; HTTP-запрос только ставит работу в очередь. Прогресс хранится по частям, успешный OCR при повторном сопоставлении не оплачивается заново.

Каждый кандидат содержит исходное значение, нормализованное значение и проверенную цитату с документом/страницей/блоком либо листом/ячейкой. Совпадающие значения объединяют источники; противоречия сохраняются отдельно. Ручной выбор и правка защищены от молчаливой перезаписи при новом распознавании. Отсутствие ответа не означает 0 или «нет».

Результаты реальной проверки и ограничения качества: [отчёт](document-ai-evaluation.md). Точные настройки API — в `MistralClient`, `Ocr`, `Mapper`, `Pipeline`; текущие модели закреплены по имени, без latest.
