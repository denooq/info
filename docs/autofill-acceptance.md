# Проверка AI-заполнения всех граф

## Текущий статус реализации v2 · 24.11.2026

PHP-набор (168 тестов), Node-набор (22 теста), TypeScript/Vite build и браузерная регрессия compact review проходят локально. Браузерный тест проверяет отображение граф, выбор источника массы, запись графы 44, каталог ТН ВЭД, курс 34.32/100 и ручную котировку; это синтетическая UI-проверка. Реальный OCR+AI-прогон новой версии графового сопоставления по корпусам ниже и четырём файлам сессии не запускался, поэтому задача 5.1/8.1 остаётся открытой. Результаты старого прогона в document-ai-evaluation.md относятся к предыдущему контракту сопоставления.

Контрольные данные `tests/fixtures/autofill-controls.v1.json` покрывают все 57 позиций для двух полных комплектов. Генератор `node tests/fixtures/autofill-controls.mjs` использует явно проверенные наблюдения из первички и списки файлов существующих reference-cpt/reference-fca. Он не используется в приложении, prompt или выборе значений AI.

`found` требует правильного значения с фактическим источником, `conflict` — сохранения разных подтверждённых значений. `profile/reference/calculated/not_applicable` имеют отдельное происхождение. `manual` означает отсутствие заранее доказанного однозначного ответа, а не запрет найти дополнительные сведения с реальным подтверждением. Текстовые проверки сравнивают существенные фрагменты, не навязывая один перевод или формат адреса.

Визуально проверены инвойс/CMR CPT и инвойс/упаковка/AWB FCA; читаемые текстовые слои контракта, приложения и других PDF дополняют проверку. У invoice FCA продавец и exporter/shipper отличаются; Ship To 060/71 нельзя заменять Bill To 062/50A. В AWB самолёт не определяется по одному номеру рейса. В CMR CPT 34 внешних паллеты и 136 бочек не суммируются, брутто 27860 конфликтует с 26792 экспортной декларации. Нетто 24480 подтверждается сопоставлением полного комплекта, а не присваивается обеим массам из одного QUANTITY.

Регрессия предоставленной сессии содержит только обезличенные наблюдения: ETHYL ACETATE не документ, 24480KGS и USD37454.40 не номера документов. Полный session JSON, csrfToken и ключ не сохраняются в фикстурах. Зарегистрированные PDF/XML и файл «Выпуск …» исключены из входов.

Для завершения приёмки необходим реальный проход OCR -> AI -> проверка -> графа по обоим комплектам и четырём файлам регрессии. Offline и replay отмечаются отдельно от live. До появления отчёта успешный HTTP либо зелёный UI-тест не доказывают заполнение. Сохранённые ответы и usage остаются только во временных сессиях с прежним TTL.
