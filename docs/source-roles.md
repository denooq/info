# Роли источников граф

`resources/registry/source-roles.v2.json` связывает реальные коды классификатора с приоритетами книги. Это внутренняя таблица маршрутизации, не словарь расширения поиска. Пользователь видит только официальное название.

| Источник книги | Официальные позиции | Проверка |
|---|---|---|
| Инвойс | 04021 | Счёт-фактура к договору; не 04031 |
| Контракт | 03011, 03012 | Сделка с товарами и её изменения |
| Товаротранспортный | 02011–02022 (существующие позиции), 02024/25/99 | В первом корпусе 02015 — конвенционная автодорожная накладная; example2 02017 — авианакладная |
| Упаковочный лист | 04131 | «Отгрузочный (упаковочный) лист»; присутствует в example2 |
| Счёт за транспорт | 04031 | Присутствует в example2; платёж 04032 и договор 04033 не подменяют его |
| Транзитная декларация | 09013 | Файл первого корпуса «тд.pdf» содержит опись: выбранный тип сам по себе не подтверждает реквизиты полной декларации |
| Сертификат происхождения | 06011/13/14/17–23 | Только реальные сертификаты с проверкой действия позиции |
| Сертификат соответствия | 01401/03 | Не источник происхождения по первому приоритету; более общая позиция 01408 без подтверждения роли не используется |
| Лицензия на ввоз | 01011 | Применимость квоты подтверждается отдельно |

Непривязанные официальные виды остаются допустимыми вложениями и документами графы 44. Поля из источников, для которых книга задаёт роль, не получают такой неподтверждённый источник: диагностика объясняет необходимость ручного заполнения/смены вида. Отказное письмо, акт идентификации, банковский платёж, СГР и брокерский договор не становятся инвойсом по имени файла. Объединённый PDF может содержать несколько юридических документов: их отдельная идентичность/страница сохраняются при распознавании, а роль вложения не является фактом о каждой странице.

Контроль `SourceRolesTest` проверяет существование каждого кода в полном справочнике, оба транспортных подвида, счёт/упаковку и ранги брутто/нетто. Проверка справочника выполняется без платного AI; это не утверждение успешного распознавания всех сканов обоих корпусов.
