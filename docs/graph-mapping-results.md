# Результаты сопоставления граф

После каждого окна сопоставления backend сохраняет проверенные предложения полей, ссылки на OCR-источники и статус результата. В публичном API для этого доступны `graphMappingResults` и `graphProjection.mappingResults`; карточки также получают `mappingStatus`, а поля — `mappingStatus` и `mappingAlternatives`.

## Статусы

| Статус | Значение |
| --- | --- |
| `found` | Есть проверенное значение и применимый источник. |
| `conflict` | Для поля найдено несколько разных значений либо новое значение расходится с ручным выбором. |
| `not_found` | Все ожидаемые источники просмотрены, и сопоставление явно подтвердило отсутствие значения. |
| `incomplete` | Обработка или привязка не завершена; отсутствие ответа не считается отсутствием данных. |
| `manual` / `selected` | Значение введено или выбрано пользователем. |
| `profile`, `reference`, `calculated`, `not_applicable` | Значение задаётся профилем, справочником, расчётом либо графа неприменима. |

Пустое значение (`null`) не создаёт предложение и не получает статус `found`. Для `not_found` требуется завершённый запуск, покрытие всех ожидаемых OCR-источников и явный результат `not_found`. Ошибка провайдера, неполное окно, отсутствующий ответ или нехватка источников оставляют результат `incomplete`.

## Варианты и редактура

Перед применением backend заново проверяет каждую цитату по серверному OCR-манифесту. Одинаковые канонические значения объединяются в один кандидат и сохраняют все ссылки на документы. Разные значения остаются отдельными кандидатами; приоритет источника влияет только на порядок показа и не скрывает конфликт.

Один допустимый кандидат заполняет поле автоматически. Несколько кандидатов оставляют поле конфликтующим. Ручное или выбранное значение сохраняется при повторном сопоставлении; новое отличающееся предложение помечает его для проверки. При запуске новой версии сопоставления старые автоматические предложения очищаются, пользовательские значения остаются.

Для страны из графы 15 название можно преобразовать в код графы 15а только при точном совпадении с официальным названием в загруженном классификаторе стран. Неоднозначное или неизвестное название остаётся предложением графы 15 и не записывается в поле кода.

Факты ДТС публикуются отдельно по матрице, полю, товару или роли участника. Текущий формат не задаёт устойчивый идентификатор для отдельных строк расходов и платежей. Такие значения показываются с источником как `incomplete` и не записываются в произвольную строку.

Публичная проекция не включает сырой ответ модели, локальные пути или ключи файлов. Ссылки на источник используют ID подтверждений из сессии.
