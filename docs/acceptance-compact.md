# Локальная приёмка компактной формы

Проверка изменения `compact-declaration-graphs`, 23.11.2026. Среда: PHP 8.3.36, Node 26.13, TypeScript/Vite, Edge headless. Доступ к хостингу не требуется. Платные вызовы Mistral не выполнялись.

| Проверка | Покрытие |
|---|---|
| PHP, 125 тестов | Domain/storage/API, оба корпуса первички, CPT/FCA, пять формул пошлины, 2/5 товаров, общие места/расходы, nominal и округление, данные ДТС, фактическая уплата, ошибки OCR/mapping, миграция |
| Node, 21 тест | HTTP gate/ревизии/TTL, каталог и manifest редакторов, буфер ввода, параллельные запросы OCR, квоты и ошибки транспорта |
| Браузер, 14 сценариев | Геометрия всех 54 карточек на 1366/1440 px, 390 px и при увеличении масштаба; 57 позиций; переключение товаров; две единицы; выбор источников мышью/клавиатурой; сохранение при 401 и задержке; полный переход и пересчёт; загрузка и завершение OCR с ошибками |
| Сборка | TypeScript/Vite, версия редакторов 3.0.0 и нормативных правил kz-im40-2026.1, manifest с SHA-256 каждого файла |
| Распакованный комплект | Без reference/config/local.php/runtime: API реестров, 54 редактора/57 позиций, справочники, ручное сохранение, миграция, вложения, запрет экспорта, наличие frontend-ресурсов |

PHP-файлы проверяются отдельными процессами при лимите 192M: `php tests/php/run.php --isolated`. Это исключает накопление больших справочников между независимыми тестами чтения сканов; производственные ограничения файлов не ослаблены. Для отдельного сценария: `php tests/php/run.php GraphCodecsTest.php`.

Вместо скрытых адресных реквизитов проверяется принятый текст графы. Пустая обязательная 8 блокирует переход даже при полной арифметике; отсутствие файла само по себе не блокирует ручные реквизиты 44. Неразбираемый текст кодовой графы и неверный новый числовой ввод остаются видимыми и запрещают расчёт по прежним значениям. Обязательные коды и единицы не заменяются произвольным текстом.

Для поддержанного стандартного случая 2026 проверены НДС 16%, МРП 4 325 и сбор 6 МРП = 25 950 ₸ один раз на ДТ при 1/2/5 товарах. Пять формул пошлины и точные распределения копеек сохранены. Для медицинских/льготных случаев, акциза, неизвестной даты/кода/применимости возвращается понятная ошибка. Фактическая уплата не выводится из начисления. Ручной итог, расходящийся с формулой, требует пересчёта.

Тесты Mistral используют подставные ответы/транспорт. Оба корпуса проверяют чтение файлов и документальные факты; числовые сценарии содержат явно заданные тестовые курсы и ручные подтверждения. Это не измерение точности реального OCR на всех файлах, юридический аудит или подтверждение совместимости с Keden. PDF/XML остаются выключенными в активном API; сохранённые тесты прежних генераторов не включают их в пользовательский сценарий.

Команды повторения перечислены в [README](../README.md); сборка, сохранение частной конфигурации и откат — в [compact-release.md](compact-release.md).

После основной приёмки воспроизведён белый экран при добавлении пустого товара: подбор ТН ВЭД создавал только замечание, без `evidenceIds`, а FieldRow читал его `.length`. Backend теперь формирует полные метаданные и для пустого/неизвестного названия, frontend принимает отсутствующий или null-список источников в старых сессиях. Повторный подбор с уже сохранённым fingerprint также дополняет метаданные, не меняя код и введённые данные. Добавлена PHP-проверка этих веток (TnvedTest.php: 9 тестов) и браузерный сценарий добавления товара, неизвестного названия, refresh и старых метаданных. Повторный браузерный набор содержит 15 сценариев.
