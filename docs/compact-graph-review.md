# Компактная форма проверки граф

Страница проверки показывает все позиции из версии графового реестра отдельными карточками в одной вертикальной колонке на любой ширине экрана. Высота каждой карточки зависит от содержимого; подписи приводятся к регистру предложения. Значения из одного источника заполняются непосредственно, альтернативы требуют выбора только при наличии двух и более вариантов. Источники остаются доступны через действие «Источник».

Неприменимые позиции сохраняются в проекции, но показываются короткой строкой. Сводные блоки замечаний и дублирующие ссылки «Причина» не используются; ошибки привязаны к соответствующему полю.

Графы 15 и 17 показывают наименование страны, а 15а и 17а — код и наименование из одного справочника стран. Для Казахстана применяется профильное значение `KZ`; неизвестный код не подменяется названием. Графа 36 стандартного неподтверждённого товара получает профильное значение «без преференции» (`hasPreference=false`, коды `ОО`). Явно распознанное или введённое наличие льготы и специальные товарные случаи не перезаписываются.

Графа 44 строится по прикреплённым файлам и распознанным записям. Исправления реквизитов отправляются с `recordId`; новый record связывается с конкретным `fileId`. Это позволяет обрабатывать несколько документов одного вида без изменения первой записи по коду. Текстовая сериализация графы не используется как адрес изменения.

Графа 33 поддерживает два источника выбора: проверенные варианты общего AI-сопоставления и поиск по локальному каталогу через `GET /api/classifiers/tnved`. AI-кандидат не создаёт код самостоятельно; после выбора карточка тарифа и единицы отображает данные выбранной записи каталога.

В графе 23 интерфейс показывает курсы за одну единицу. Исходные значения `value`/`nominal` НБК остаются в модели без округления и участвуют в расчёте; например, `34.32 / 100` отображается как `0.3432`. Ручной курс сохраняется одной операцией с `nominal=1`, датой декларации, подтверждением и источником `manual`. Курсы KZT заданы как `1`.

Проверки браузерного отображения, поиска/выбора ТН ВЭД, привязки файла графы 44, курса и ручного редактирования выполняются в `tests/compact-review.browser.mjs`. Ошибка сопоставления отдельно от пустых граф объясняется на странице проверки; повтор использует сохранённый OCR и отображает ход окон без создания OCR-задач. Проверка разметки формы не является проверкой live-ответа Mistral.
