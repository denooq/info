# Tasks

План компактной формы и автоматических нормативных величин по последним решениям Explore. Пункты относятся к реализации после отдельного запроса apply; сейчас код не меняется. Прежние 37 выполненных задач customs-declaration-mvp сохраняются. Размещение, настройка и проверки PS.kz, изменение worker/cron, платный прогон Mistral и восстановление экспорта не входят в этот список. Зависимости: 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7; целевые тесты и документация выполняются вместе с каждым изменением.
