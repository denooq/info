# Spec Delta

## Purpose

Заполнять графу 33 и связанные параметры товара по уже предоставленному полному каталогу ТН ВЭД, сохраняя происхождение решения и проверку применимости тарифов.

## ADDED Requirements

### Requirement: Reuse the supplied complete commodity catalogue
Справочный подбор MUST использовать reference/TNVED/tnved.json и подготовленные из него runtime-данные. Автоматический код SHALL быть существующим конечным десятизначным кодом; ведущие нули, название, версия, единицы, базовая формула и сноски SHALL сохраняться. Второй независимый каталог MUST NOT создаваться.

#### Scenario: Verify the provided catalogue import
- **WHEN** подготавливается версия справочника из текущего JSON
- **THEN** проверяются 18014 записей и 13294 конечных кода, родители и происхождение данных
- **AND** справочник доступен на хостинге без загрузки 38-МБ исходника на каждый запрос

### Requirement: Check documentary codes before name matching
Код, найденный в допустимом документе по приоритетам графы 33, MUST проверяться по каталогу. Если кода нет, SHALL выполняться поиск по подтверждённому наименованию. AI MUST NOT придумывать код или отсутствующие свойства товара; неоднозначность SHALL сохранять варианты, неизвестное название — неизвестный код.

#### Scenario: Search a distinct product name
- **WHEN** подтверждено наименование «этилацетат» без документального кода
- **THEN** единственное точное совпадение 2915310000 подставляется из каталога со справочным источником

#### Scenario: A documentary code is outside the catalogue
- **WHEN** первичка содержит код, которого нет в принятой версии
- **THEN** код не заменяется молча похожим товаром и не считается автоматически проверенным
- **AND** показаны документ, значение и необходимость уточнить код или актуальность справочника

### Requirement: Preserve independent item decisions
Каждый товар SHALL иметь собственный код и кандидаты. Единственное точное справочное совпадение SHALL заполняться без кнопки, неоднозначные — показываться для выбора. Ручной или выбранный документальный код MUST NOT перезаписываться подбором; смена описания SHALL пересматривать только автоматические предложения.

#### Scenario: Edit the second item description
- **WHEN** пользователь изменяет описание второго товара после автоматического подбора
- **THEN** его предложения обновляются без изменения первого товара и без потери ручных решений
- **AND** прежний расчёт теряет актуальность

### Requirement: Source tariff units and confirm applicability
Базовая ставка, единицы и сноски SHALL браться из того же каталога. Базовая формула MUST NOT объявляться действующей без проверки контекста. Количества, НДС, сборы и отсутствующие параметры MUST NOT выдумываться; применимость и необходимые входы SHALL подтверждаться на соответствующей странице.

#### Scenario: Additional unit requires an unknown quantity
- **WHEN** код требует дополнительную единицу, но количество в первичке не найдено
- **THEN** единица графы 41 заполнена справочником, а неизвестное количество требует ввода
- **AND** ни единица ставки, ни масса другого товара не подменяют это количество

#### Scenario: A zero base rate is applicable
- **WHEN** каталог содержит нулевую ставку и её применимость подтверждена
- **THEN** ноль остаётся известным значением и не превращается в пустое поле или неизвестную ставку
