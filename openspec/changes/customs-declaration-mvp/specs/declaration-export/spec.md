# Spec Delta

## Purpose

Явно исключать прежнюю выдачу PDF/XML из текущего трёхстраничного MVP, чтобы пользователь завершал работу на расчёте без требований снятого формата экспорта.

## ADDED Requirements

### Requirement: Disable generation and downloads in the current profile
В текущем профиле система MUST NOT показывать четвёртую страницу, «Создать», «Скачать PDF» и «Скачать XML», запускать генерацию или выдавать прежние файлы. Прямые запросы прежних операций SHALL возвращать понятный статус недоступности функции без создания задания.

#### Scenario: Request an old generation endpoint
- **WHEN** клиент обращается к прежнему созданию или скачиванию после обновления
- **THEN** генерация и выдача не выполняются, ответ объясняет отсутствие функции в текущем MVP
- **AND** пользователь сохраняет доступ к графам и расчёту своей сессии

### Requirement: Remove export prerequisites from graph review and calculation
Отсутствие XSD, расширения Keden, неподдерживаемые ветки XML и технические поля формата MUST NOT блокировать графы или расчёт. Служебные номера, статусы регистрации/выпуска и ЭП MUST NOT присваиваться новой декларации. Примеры SHALL оставаться только проверочными материалами.

#### Scenario: Calculate a case absent from the sample XML
- **WHEN** заполнены действительные входы расчёта специфической пошлины или вычета метода 1, отсутствующего в образце XML
- **THEN** расчёт выполняется в рамках поддержанных формул без ошибки XML_BRANCH_UNSUPPORTED
- **AND** приложение не обещает совместимость с Keden и не создаёт регистрационные реквизиты

### Requirement: Preserve source work independently of legacy exports
Отключение выдачи MUST NOT удалять первичные файлы, OCR, ручные значения и текущие расчётные входы активной сессии. Старые результаты SHALL очищаться по прежнему сроку хранения без постоянного архива и истории.

#### Scenario: Open a session that previously had ready files
- **WHEN** обновлённое приложение открывает ещё действующую сессию со старым комплектом
- **THEN** старые кнопки и файлы не выдаются как текущая функция, а исходные сведения остаются доступны после согласованного обновления модели
