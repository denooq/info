# Spec Delta

## Purpose

Предоставлять единые официальные коды видов документов и стран для загрузки, заполнения граф и проверки данных без самодельных сокращённых каталогов.

## ADDED Requirements

### Requirement: Use a complete versioned official document classifier
Система MUST использовать полный официальный классификатор видов документов и сведений из приложения 8 к решению №378. Версия, источник, область применения и актуальность SHALL быть известны. Каталог MUST NOT подменяться списком примеров или сокращённым перечнем разработчика.

#### Scenario: Inspect the available document types
- **WHEN** пользователь открывает выбор вида документа
- **THEN** доступны действующие позиции принятой полной версии классификатора с официальными кодами и наименованиями
- **AND** отменённые или неприменимые к выбранному контексту позиции не принимаются как допустимые без объяснения

### Requirement: Search document types only by official name or code
Поиск SHALL использовать только код и официальное наименование выбранной версии. Синонимы, альтернативные названия, перевод, транслитерация и AI-подбор названий MUST NOT расширять поиск. Техническая нормализация регистра и пробелов SHALL сохранять исходное официальное отображение.

#### Scenario: Search for an invoice
- **WHEN** пользователь вводит 04021 или фрагмент официального наименования позиции
- **THEN** результат показывает её официальный код и наименование
- **AND** термин, отсутствующий в коде и официальном наименовании, не получает результат через скрытый словарь синонимов

### Requirement: Preserve the selected official document identity
Выбранный код SHALL сохраняться вместе с версией каталога и использоваться для источников граф и перечня документов графы 44. Система MUST NOT создавать пользовательские псевдокоды для не найденного вида. Несоответствие содержания выбранному виду SHALL быть видимым и требовать исправления.

#### Scenario: A familiar name has no separate classifier position
- **WHEN** отдельная позиция «Упаковочный лист» не найдена в принятой версии
- **THEN** система не добавляет такой вид с придуманным кодом или синонимом
- **AND** пользователь выбирает применимую официальную позицию; неподтверждённая связь с правилом источника остаётся явно нерешённой

### Requirement: Use one official alphabetic country code model
Система MUST использовать единый полный классификатор стран из приложения 22 к решению №378 с указанными в нём кодами. Казахстан SHALL иметь код KZ в форме и данных; комментарий 398 из пользовательской книги MUST NOT задавать альтернативное представление этой графы.

#### Scenario: Fill the destination country
- **WHEN** применяется профиль импорта ИМ 40 в Казахстан
- **THEN** графа 17 содержит официальное наименование Казахстана, а 17а — KZ
- **AND** форма и сохранённые данные не содержат отдельного числового варианта 398 для этой страны
